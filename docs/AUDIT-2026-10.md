# OverMobile audit — October 2026

Point-in-time review of OverMobile after the OverBuild Labs rebrand (main at
`53a8230`, v1.2.0 + PRs #28/#29). Three parallel reviews: security, Kotlin
correctness/concurrency, native C/JNI. Findings were checked against the code
before fixing. Fixes landed on branch `claude/audit-hardening-roadmap`.

**Verification:** native changes were compiled on the host and a 4-thread
start/stop stress test passes under ThreadSanitizer; the difficulty→target
maths was checked against exact big-integer arithmetic. Kotlin outside the
Compose UI was type-checked with kotlinc 1.9.22 against the Android 14 API
(`tools/typecheck/`). Nothing was built with Gradle or run on a device in the
cloud session — that is the maintainer's smoke test before merging.

Status: **Fixed** = in this branch · **Roadmap** = open, tracked in
[`ROADMAP.md`](ROADMAP.md) under the given id.

## Security

| # | Sev | Finding | Status |
|---|---|---|---|
| S1 | High | OverManager commands (`set_config`, `start`, …) arrive in plain-HTTP report responses with no authentication of the server. Anyone who can spoof the server on the LAN can change the payout wallet/pool and take the hashrate. `set_config` also skipped input validation. | Partly fixed: remote values now pass `FieldValidators`, a remote wallet change is logged in-app. **Roadmap R1** (signed commands / pinned HTTPS — needs OverManager changes). |
| S2 | Med | Changing the OverManager server URL kept the old server's API key and report URL, so the old server kept control. | Fixed — credentials are bound to the issuing server (`creds_server_url`). |
| S3 | Med | The server-supplied `reportUrl` was trusted verbatim, so a spoofed `/register` response could redirect the key and telemetry to any host. | Fixed — only its path is used, against the configured server. |
| S4 | Med | `nextReportIn` ≤ 0 made the report loop post continuously. | Fixed — clamped to 10–3600 s. |
| S5 | Med | Crashes from remote input: over-long extranonce (exception on the JNI thread → process death), malformed pairing QR fields on the main thread. | Fixed. |
| S6 | Med | Unbounded reads: stratum `readLine()`, OverManager and GitHub response bodies. | Fixed — 64 KB line cap, 1 MB body caps. |
| S7 | Med | Pairing QR accepted any URL/code. | Fixed — http(s) URL + 6-digit code required; the target host is shown. |
| S8 | Low/Med | Update APK installed with no hash/signature/package check; any URL accepted. | Fixed — `ApkVerifier` (GitHub SHA-256 digest, package name, signer) on both install paths; URL allow-list. Download still lands in app-specific external storage on API 26–28 (**Roadmap R9**). |
| S9 | Low | `allowBackup` without rules backed up the OverManager API key and device id. | Fixed — `data_extraction_rules.xml` / `backup_rules.xml`. |
| S10 | Low | `usesCleartextTraffic="true"` app-wide. | **Roadmap R1** (goes away with HTTPS to OverManager). |
| S11 | Low | `mining.submit` built by string interpolation. | Fixed — Gson. |
| S12 | Low | Wallet and command params in release logcat. | Fixed for stratum + commands; general debug-log stripping is **Roadmap R10**. |
| S13 | Info | Stratum is plain TCP (inherent to `stratum+tcp`). | **Roadmap F3** (stratum over TLS). |

Checked and fine: `InstallReceiver` is protected by `SEND_DOWNLOAD_COMPLETED_INTENTS` and matches the stored download id; activities/service not exported; FileProvider not exported and narrowly scoped; `PendingIntent`s immutable and explicit; no hardcoded secrets; default TLS validation; update notes rendered as plain text; the update repo (`overbuildlabs/overmobile`) is the same repository the old `proofofprints/PoPMobile` URL redirects to.

## Correctness — Kotlin

| # | Sev | Finding | Status |
|---|---|---|---|
| K1 | High | A clean close by the pool was never reported, and `Socket.isConnected` stays true after the peer leaves, so reconnect never ran. | Fixed — own liveness flag, EOF = disconnect, per-connection generation. |
| K2 | High | Remote `set_config` that changed the pool stopped mining for good (`engineStartedOnce` stayed true). | Fixed. |
| K3 | High | `startMining` not idempotent: duplicate connections/stats loops, leaked wake lock; remote start/stop ignored paused/connecting sessions. | Fixed. |
| K4 | Med | Engine start/stop raced across four threads. | Fixed (native control mutex + `@Synchronized`). |
| K5 | Med | Stop could ANR: workers wrote shares to the socket from the JNI callback while stop joined them on the main thread. | Fixed — disconnect before join; shares submitted on IO. Stop still joins on the main thread (bounded by one hash batch) — **Roadmap R6**. |
| K6 | Med | No resume after a pause on devices without a sysfs temperature. | Fixed. Battery-WARNING band still blocks resume while charging — **Roadmap R5**. |
| K7 | Med | First pairing didn't start the report loop / foreground service. | Fixed. |
| K8 | Med | Concurrent `sendReport` could run a command twice and drop acks. | Fixed. |
| K9 | Med | `startMining` took locks before `startForeground`; a background start on Android 12+ left a half-started session. | Fixed. Null-intent `START_STICKY` restarts — **Roadmap R6**. |
| K10 | Med | Fresh install: default pool URL wiped by the 1 s prefs poll. | Fixed. |
| K11 | Med | `"body": null` in a release hid the update. | Fixed. |
| K12 | Med | Malformed pairing QR crashed the app. | Fixed (S5). |
| K13 | Med | 4-hour wake-lock timeout on 24/7 sessions. | Fixed — renewed. |
| K14 | Low | `InstallReceiver` `startActivity` from background is blocked on Android 10+. | **Roadmap R7**. |
| K15 | Low | Rotation cancelled the update download. | Fixed. |
| K16 | Low | `VersionCompare` ignores `-rcN` suffixes. | **Roadmap R8**. |
| K17 | Low | Extranonce carried across connections; over-long extranonce; non-atomic message ids. | Fixed. |
| K18 | Low | Throttle restarts zeroed the accepted-shares count. | Fixed — `nativeResetStats` at session start only. |
| K19 | Low | Service binding edge cases in `MainActivity` (unbind before connect; `startForegroundService` from async bind callback). | **Roadmap R6**. |
| K20 | Low | Thread slider crash on one-core devices; >8 threads offered. | Fixed in UI; remote `set_threads` still accepts up to 16 (engine clamps to 8, UI shows the requested number) — **Roadmap R11**. |
| K21 | Low | Thermal diagnostics file I/O on the main thread; reporter scope never cancelled. | **Roadmap R12**. |
| K22 | Low | Missing `PROPERTY_SPECIAL_USE_FGS_SUBTYPE`. | Fixed. |

## Correctness — native / JNI

| # | Sev | Finding | Status |
|---|---|---|---|
| N1 | High | `set_target_from_difficulty` truncated `1/difficulty` to an integer: difficulty > 1 → difficulty-1 target; fractional difficulties off by up to ~10 %; NaN was UB. | Fixed — exact to double precision (checked 1e-12 … 1e300). |
| N2 | High | Unlocked `mining_start`/`mining_stop` → hang or abort when they race. | Fixed — control mutex; atomic run flags. |
| N3 | High | `pthread_create`/`malloc` unchecked → join on a garbage handle. | Fixed. |
| N4 | Med | Pending Kotlin exception in the share callback killed the process on detach; uninitialised `env`. | Fixed. |
| N5 | Med | Callback global ref swapped while workers used it; never released on destroy. | Fixed — rwlock; released in `onDestroy`. |
| N6 | Med | Extranonce bit counts outside 8..64 → stuck nonce or UB shift. | Fixed (both sides). |
| N7 | Med | Nonce start could carry into the extranonce prefix. | Fixed. |
| N8 | Med | Shares submitted synchronously on hashing threads; duplicate message ids. | Fixed. |
| N9 | Low | `nativeSetJob` copied 32 bytes without length checks. | Fixed. |
| N10 | Low | Extranonce prefix/mask torn reads. | Fixed — written and read together under `job_mutex`. |
| N11 | Low | `has_job` survives stop (stale job after a pool switch until the next notify); job ids > 64 chars truncated. | **Roadmap R13**. |
| N12 | Low | Two shared atomic adds per hash on one cache line; 64-bit counters can tear on armeabi-v7a. | **Roadmap P1** (performance). |
| N13 | Low | Self-test result ignored; debug builds compile hashing at `-O0`. | **Roadmap R13**. |
| N14 | Build | 16 KB page support. | Partly fixed — ELF `max-page-size=16384`, static STL. Zip alignment needs AGP ≥ 8.5.1 + NDK r27+ — **Roadmap R2**. |
