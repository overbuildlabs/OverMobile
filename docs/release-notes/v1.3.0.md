# OverMobile v1.3.0

A big stability and security update. Mining works with public pools such as
HeroMiners, thermal protection now recovers properly, settings apply without
restarting the miner, and the app updates itself only from verified OverBuild
Labs releases. Pair it with **OverManager v1.9.2** for the pairing countdown
and the security fixes on the desktop side.

## What's new

- **Works with public pools.** The pool login and nonce handling now follow
  what public pools expect, and share difficulties above 1 are computed
  correctly. Before, most shares on those pools would have been rejected.
- **Changing threads no longer interrupts mining.** A thermal throttle, the
  restore after cooling, or a new thread count from Settings or OverManager
  only swaps the worker threads, so the hashrate no longer drops to 0.
- **Thermal throttling recovers.** After throttling, the phone goes back to
  full threads once it cools, even if the temperature wobbles by a degree.
  The banner shows when you're throttled and counts down the restore.
- **OverManager sees a stuck throttle.** The phone keeps reporting that it's
  throttled until full threads are back, so OverManager's thermal indicator
  and throttle alert catch a phone that never recovers. Settings also warns
  when the resume temperature is set too close to the throttle temperature.
- **Settings has Save / Cancel.** A bar stays pinned at the top of Settings.
  All settings, including thermal and power protection, apply only when you
  save, and leaving with unsaved changes asks first. Saved changes apply to
  a running session right away.
- **Pairing controls.** Remove a pairing or re-pair with a new code from the
  OverManager card. After too many wrong codes, a countdown shows when you
  can try again. If OverManager removes the phone, the card updates straight
  away.
- **Pauses behave.** "Require charging" and low-battery pauses hold until
  their cause clears, and mining resumes once the phone charges past the
  cutoff + 5 %.
- **Reconnects after a pool drop**, and a pool that rejects your wallet or
  worker name now says so instead of hashing silently.
- **New OverMobile icon and pool.** OverMobile has its own icon. Installs
  that used `pool.proofofprints.com` move to `pool.overbuildlabs.com`
  automatically; any other pool you saved is left alone.

## Security

- **Updates are verified before install**: the APK must match its published
  SHA-256 and be signed by OverBuild Labs.
- **Remote settings from OverManager are validated**, and a remote change of
  the payout wallet is written to the log.
- **Pairing is tied to its server.** Changing the OverManager address drops
  the old pairing.
- **The OverManager key is excluded from Android backups.**

See the [changelog](https://github.com/overbuildlabs/OverMobile/blob/main/CHANGELOG.md)
for every change.

## Upgrading from v1.2.0

Seamless in-place upgrade. Wallet, pool, settings and OverManager pairing are
kept. Accept the in-app update prompt, or download the APK below.

## Checksums

- Windows: `certutil -hashfile popmobile-v1.3.0.apk SHA256`
- macOS / Linux: `shasum -a 256 popmobile-v1.3.0.apk`

SHA-256: `PASTE_HASH_HERE`

Or verify against the `.sha256` file in the assets:

- Linux / macOS: `sha256sum -c popmobile-v1.3.0.apk.sha256`
